# 🖼️ Image Editor (Vanilla JavaScript)

A simple, fast, and lightweight **browser-based image editor** built using **HTML, CSS, and Vanilla JavaScript**.  
This project allows users to upload an image, apply real-time visual filters, use preset styles, reset changes, and download the edited image — all without any backend.

---

## ✨ Features

- 📂 Upload images directly from your device
- 🎛️ Real-time image filters using sliders:
  - Brightness
  - Contrast
  - Saturation
  - Hue Rotation
  - Blur
  - Grayscale
  - Sepia
  - Opacity
  - Invert
- 🎨 One-click preset effects:
  - Normal
  - Drama
  - Vintage
  - Old School
  - Black & White
  - Cinematic
  - Faded
  - Warm
  - Cool
  - Horror
  - Dreamy
- 🔄 Reset all filters instantly
- 💾 Download the edited image as a JPG
- ⚡ Fully client-side (no server required)

---

## 🛠️ Built With

- **HTML5**
- **CSS3** (Custom theme variables)
- **JavaScript (Vanilla)**
- **Canvas API**

---

## 📸 How It Works

1. Select an image using the **Choose Image** button
2. Adjust filters using sliders (changes apply instantly)
3. Try preset styles for quick edits
4. Click **Reset** to revert changes
5. Click **Download** to save the edited image
